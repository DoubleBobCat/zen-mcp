# 数据库设计：Zen MCP 浏览器自动化

[English](Database-Design.md) | [简体中文](Database-Design_zh.md)

## 适用性

zen-mcp 没有项目自有数据库和持久化存储层。工作区、文件夹、置顶标签页和会话状态仍由 Zen Browser 负责。

## 临时模型

### MCP 会话

Go bridge 保存 `sessionId`、连接状态、最后活动时间、进行中的请求数量和空闲清理定时器。

### 会话标签页所有权

扩展保存 MCP `sessionId` 到浏览器 `tabId` 的映射。共享标签页会保持打开，直到最后一个活动所有者过期。

### 标签页切换锁

扩展保存一个锁，包含所有者会话 id、获取时间、过期时间以及显式/操作范围状态。

### 网络会话

网络管理器保存 id、所有者会话 id、标签页 id、过期时间和有大小限制的请求记录。记录包含请求/响应元数据和主体可用性状态，捕获的凭据请求头在 MCP 响应前会被移除。

### 重放规则

响应覆盖作为一次性的精确 URL/方法规则保存，在使用或过期后删除。

## 生命周期

bridge 或扩展停止时，所有模型都会丢弃。停止捕获、标签页关闭、所有者会话清理或达到 15 分钟限制时，网络状态也会被删除。不需要迁移、备份、索引、加密或数据库监控。
