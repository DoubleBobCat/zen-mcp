# 适用性决策

[English](applicability.md) | [简体中文](applicability_zh.md)

本仓库为 documentation-first-engineering 的所有阶段保留了当前文档。没有阶段通过历史缓存或未经审阅的占位决策满足。

- 阶段 5 Plugin-Spec：适用。`docs/specs/Plugin-Spec.md` 描述当前浏览器扩展包和运行时边界。
- 阶段 5 MCP-Spec：适用。`docs/specs/MCP-Spec.md` 描述当前可调用工具契约。
- 阶段 5 Workflow-Spec：适用。`docs/specs/Workflow-Spec.md` 描述当前 bridge 到扩展的请求生命周期。
- 阶段 5 Event-Spec：适用。`docs/specs/Event-Spec.md` 记录没有公共事件 API 以及内部断开控制消息。
- 阶段 6 Data Design：适用。`docs/Database-Design.md` 描述当前临时内存状态和项目自有存储缺失。
- 阶段 7 API Design：适用。`docs/API/openapi.yaml` 描述 Streamable HTTP 适配器和已实现工具清单。
- 阶段 10 Deployment/Operation：适用。`docs/Deployment.md` 和 `docs/Operation.md` 描述当前本地打包和服务流程。
